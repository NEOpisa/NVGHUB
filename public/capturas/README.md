# Capturas reais do Neovanguard OS

Salvar aqui quatro arquivos WebP em 1600 × 1000 px (16:10), idealmente até
250 KB cada. A home detecta os arquivos durante o build; depois de adicioná-los,
rodar `npm run build`. Sem o arquivo, o espaço mostra “Captura em preparação”.

- `plasma-desktop.webp`: desktop KDE Plasma pronto, na MBN Live.
- `instalador.webp`: uma das sete etapas do instalador da MBN Install.
- `neo-status.webp`: terminal executando o comando real `neo-status`.
- `identidade-nostr.webp`: interface real de carteira/identidade Nostr.

Usar uma conta de demonstração. Não incluir seed, nsec, chaves privadas ou
outros dados pessoais. Não substituir por montagem de interface ou imagem gerada.
